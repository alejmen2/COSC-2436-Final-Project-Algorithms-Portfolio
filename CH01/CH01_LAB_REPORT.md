## Reflection Questions

1. **Explain binary search to someone who has never programmed.**
   Binary search is a fast way to find something in a sorted list. Breaking down looking for a book between halves. First half of the book, second half of the book, then the halves of those and the cycle continues until found.

2. **Doubling the list adds only one step to binary search. Why does that happen?**
   It happens because each guess in binary search cuts the remaining list in half.

3. **Where does binary search show up in real software?**
   Games where you have to Quickly find objects or values in organized data.
